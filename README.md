TV에 조별 탑, 방금 쓴 문장, 시상식. 효과음(Web Audio, 파일 없음)과 소리 끄기, 3·2·1 시작, 마지막 1분 피버 타임(3분 넘는 판, 블록 2배), 정답 꽃가루와 영어 문장 읽어 주기(🔊 듣기). 9단원 문장 그림·첫 화면 그림·조 마스코트는 선생님 컴퓨터의 Codex로 그렸어요(`tower/img/`). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.

- `stock/` 우리 반 쿠키 증권 (3주 모의 주식 투자 프로젝트, 학급 LMS "다했니?" 쿠키로 투자): 가상 회사 13개, ETF 5개(우리반 전체·미래기술·생활·즐길 거리·수출, 담긴 회사 평균을 따라감), 금(천천히 움직이는 안전 자산), 🏦 은행(달러 환전, 예금 하루 이자 0.3% 복리, 하루 500~3,000원씩 5번 넣는 적금 만기 이자 3%, 📜 채권: 나라 채권 2%·바로마트 채권 4%·반짝엔터 채권 8%를 5일 뒤 만기까지 들고 있고 중간에 못 팖, 회사 채권은 그동안 그 회사 주가가 15% 넘게 떨어지면 80%만 돌려받음, 끝날 때 만기 전이면 원금만). 사회 2단원 무역·시장경제와 연결돼요. 매일 아침 선생님이 "새 날 시작"을 누르면 어제 뉴스의 영향으로 주가와 환율이 바뀌고(회사마다 꾸준히 크는 힘 + 뉴스 영향 + 운 − 어제 뉴스로 움직인 만큼 조금 되돌림, 하루 ±20% 제한), 오늘의 뉴스가 나오고 장이 열려요. **건전한 투자가 이기도록** 사고팔 때마다 수수료(주식 1%, ETF 0.3%, 금 0.5%, 최소 10원)가 붙고 산 지 3일 안에 팔면 단기 매매 수수료 3%가 더 붙어요. 시뮬레이션(4,000번)에서 ETF를 사서 그대로 두면 평균 +6%, 뉴스를 정확히 읽고 매일 갈아타면 평균 −3%, 어제 오른 것을 매일 따라 사면 평균 −50%예요. 학생 지갑에 거래 횟수·낸 수수료·바구니 수(분산 정도)가 보여요. 투자 습관 장치: 회사 분석 카드(돈을 버는 방법·좋아지는 때·나빠지는 때·흔들림 정도), 뉴스 출처 표시와 다음 날 해설(소문·유튜버 뉴스는 영향 없음), 살 때 까닭 고르기(투자 일기), 하루 거래 3번 제한, 한 회사에 자산 절반 넘게 담으면 경고, 나의 목표와 투자 원칙. **여러 컴퓨터에서 관리**: 💾 메뉴에서 비밀번호를 정하면 장부(다했니 설정 포함)를 AES-GCM으로 잠가 `rooms/<방>/vault`에 저장하고, 다른 컴퓨터에서 방 번호와 비밀번호로 이어받아요. 이어받으면 원래 창은 멈춰요(`boss` 기록은 비밀번호 열쇠로 서명해서 학생이 흉내 낼 수 없어요). 장은 설정한 시각(기본 오후 1시 10분)에 닫혀요. 뉴스 36개가 준비되어 있고 선생님이 우리 반 일로 직접 쓸 수도 있어요(영향은 꾹 눌러야 보여서 TV에 안 드러나요). 학생은 시장(사고팔기, 🌟 쉬운 화면은 한 주씩)·뉴스(오를/내릴 회사 예측과 까닭, 맞히면 뉴스 해석왕 점수)·내 지갑(평균 산 값·손익·수익률)·쿠키(맡기기·쿠키로 바꾸기) 화면을 써요. **다했니 API는 읽기 전용**이라 쿠키를 빼고 주는 일은 선생님이 다했니에서 하고, 🍪 쿠키 처리 화면이 "누구에게 몇 개"를 보여 주고 API로 정말 바뀌었는지 확인해요(사용한 쿠키·받은 쿠키가 늘었는지). API 키와 학생 코드는 선생님 컴퓨터 localStorage에만 두고 서버에 올리지 않아요. 진짜 쿠키가 걸려 있어서 **장부는 선생님 컴퓨터에만** 있고(Firebase `pub`은 보여 주기용 복사본, 누가 고치면 바로 되돌림), 학생 기기마다 만든 열쇠(ECDSA)로 서명한 주문만 받아요(다른 친구 이름 주문·고친 주문·마감 뒤 주문은 막힘). 계좌는 선생님이 승인해요(학생 화면과 같은 그림 두 개로 기기 확인). 마지막 날 "프로젝트 끝내기"를 누르면 모든 주식을 팔아 쿠키로 바꾼 정산표가 나오고, 시상식(수익률왕·뉴스 해석왕·분산 투자왕·꾸준한 투자왕, 반 전체가 낸 수수료). 💾 장부 백업 파일로 다른 컴퓨터로 옮길 수 있어요. 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.

## 학생 화면 보기 (모든 실시간 게임 공통, `common/watch.js`)

- 선생님 화면 왼쪽 아래 **👀 학생 화면** 버튼: 학생마다 같은 크기의 글자 카드로 보여요. 번호·이름, 지금 단계, 지금 하는 일(문제, 쓰고 있는 글자, 화면에 뜬 안내, 들어가기에서 아직 안 한 것), 도움 요청, 1분 넘게 그대로, 연결 끊김. 카드를 누르면 그 학생 화면을 태블릿 세로 크기(820px)로 고정해 잘림 없이 보여 줘요(기기 크기·회전·스크롤과 상관없이).
- **단계별 화면** 탭: 활동의 모든 단계를 순서대로 한눈에 보여 줘요(지나온 단계 포함). 단계마다 입력 글자를 지운 예시 화면, 지금 그 단계에 있는 학생 수와 번호가 나와요. 단계를 누르면 태블릿 테두리 속 큰 안내용 화면과 이전/다음 단계 버튼이 나와서 TV로 "지금 이 화면이에요" 하고 안내할 수 있어요. 학생 카드를 눌러 보는 화면은 🔴 실시간 표시가 붙은 그 학생의 실제 화면이에요.
- 학생 화면 오른쪽 아래 **🙋 도와주세요** 버튼: 선생님 화면에 알림과 소리가 나고, 선생님이 "확인했어요"를 누르면 학생 화면에 알려요.
- 학생 들어가기 화면: QR로 들어오면 방 번호는 확인 표시만, "번호"와 "이름" 칸을 나눠서(한 칸에 "7 김민수"로 써도 나눠 줘요), 무엇이 빠져서 버튼이 안 눌리는지 바로 아래 할 일 목록으로 보여 줘요.
- **📱 내 휴대폰으로 보기**: `?room=방번호#watch` 주소(QR)로 선생님 휴대폰에서 학생 화면만 볼 수 있어요. TV에는 띄우지 않아도 돼요.
- 데이터는 Firebase `rooms/<방 번호>_watch/` 아래에 저장해요(게임 방 데이터와 따로라 TV가 느려지지 않아요).
