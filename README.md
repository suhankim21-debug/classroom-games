# classroom-games

6학년 수업에서 쓰는 웹 게임 모음입니다. GitHub Pages로 배포합니다.

- `trade/` 무역 왕국 (사회 2단원 13차시): 짝이 한 나라가 되어 자원을 주고받아 상품을 만드는 실시간 게임. 실시간 데이터는 Firebase Realtime Database의 `rooms/` 아래에 저장됩니다.
- `urimal/` 우리말 지킴이 (국어 4단원 8~10차시를 한 차시로): 학생 한 명이 태블릿 한 대로 언어생활 점검 → 바꿔 말하기 미션 → 실천 다짐문 쓰기 → 친구 다짐문에 의견 주고 고쳐 쓰기 → 스스로 점검·챌린지까지 해요. 교사 화면이 단계를 열고, 우리 반 점검 결과 그래프와 다짐문 모음을 보여 줘요.
- `circle/` 원의 둘레와 넓이 실험실 (수학 5단원 2~6차시): 원리를 눈으로 보여 주는 시뮬레이터. ① 원 굴리기(원주는 지름의 3배보다 조금 김, 정육각형·정사각형 비교) ② 원주율 찾기(물건마다 원주를 펼쳐 지름 막대로 재기, 표·그래프, 원주·지름 계산) ③ 넓이 어림하기(모눈, 안쪽·바깥 정사각형, 반지름 정사각형 몇 개) ④ 잘라 붙이기(부채꼴을 엇갈려 붙여 직사각형으로). 서버 없이 TV와 태블릿 어디서나 열려요.
- `wonju/` 원주 탐험대 (수학 5단원 2차시, 학생 참여형 실시간): 원의 구성 요소 다시 보기 → 원 굴리기 실험(원주와 지름 3개·4개 비교, 원 안 정육각형·원 밖 정사각형) → 짝과 교실의 둥근 물건을 재어 올리면 TV에 지름-원주 그래프 → 원주 어림 대결(12문제, 순위표와 시상식). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `ai/` 우리 반 AI 연구소 (실과 5단원 생활 속 인공지능 5~6차시 "인공지능이 만들어지는 과정을 체험해 볼까요", 학생 참여형 실시간): 교과서의 네 단계(데이터 수집하기 → 모델 학습하기 → 프로그래밍하기 → 모델 평가하기) 순서 맞히기 → 학생들이 삼각형·사각형·원을 그려 우리 반 데이터 모으기(TV에서 이상한 데이터 지우기) → 교사가 TV에서 모델을 학습시키면 학생이 새 그림(평가용 데이터)으로 평가(많이 배운 AI와 조금 배운 AI 비교, 배우지 않은 것 보여 주기) → AI 퀴즈 대결과 시상식. AI는 브라우저 안에서 가장 닮은 그림을 찾는 방식(k-최근접 이웃)으로 동작해요. 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `tower/` 문장 탑 쌓기 (영어 쓰기 게임, 학생 참여형 실시간): 그림과 우리말 뜻을 보고 영어로 쓰면 우리 조 탑에 블록이 쌓여요. 학생이 단계를 골라요: ⭐ 낱말 카드 배열(블록 1) · ⭐⭐ 빈칸 쓰기(블록 2) · ⭐⭐⭐ 문장 전체 쓰기(블록 3). 틀리면 틀린 낱말을 빨갛게 보여 주고, 두 번 틀리면 정답을 보고 따라 쓰기(블록 1), 한 번에 3문제 연속이면 황금 블록. 대소문자·문장부호·줄임말(I'm = I am)은 봐줘요. 교사 화면에서 문장 세트(YBM 최희경 6학년 9단원 등)를 고르거나 `그림 | 우리말 | 영어 [빈칸]` 형식으로 직접 넣고, 시간·조 수를 정해요. TV에 조별 탑, 방금 쓴 문장, 시상식. 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `tradelab/` 무역 실험실 (사회 2단원 14차시 "무역이 이루어지는 까닭을 알아볼까요", 학생 참여형 실시간): 짝이 한 나라(들판·솜씨·사막·기술·바다나라)가 되어요. 1 만약에 카드(교과서 97쪽, 비행기 기술·천연가스가 없다면?) → 무역이 필요한 까닭 쓰기(TV에 모음) → 2 1라운드: 국경을 닫고 일손 10명으로 쌀·옷·천연가스·스마트폰·생선을 모두 혼자 만들기(사막나라는 쌀을 못 만들어 꾸러미 0개) → 3 2라운드: 잘 만드는 상품에 일손을 모으고 다른 나라와 제안·수락으로 바꾸기(TV에 나라별 1·2라운드 비교 그래프, 무역 소식, 수출/수입) → 4 정리 퀴즈 대결(흑연·전기차 배터리 사례 포함, 보기 2개 쉬운 모드)과 시상식. 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.

## 자동 테스트

`node tests/trade-e2e.js` 로 배포된 무역 왕국을 Playwright로 끝까지 플레이해 봅니다 (교사 1 + 학생 5나라, 보내기 29번, 상품 10개). 테스트 방은 끝나면 지웁니다.

`node tests/urimal-e2e.js` 로 우리말 지킴이를 교사 1 + 학생 8명으로 1~4단계 끝까지 해 봅니다.

`node tests/circle-e2e.js` 로 원의 둘레와 넓이 실험실의 네 화면을 차례로 눌러 보고 오류가 없는지, 원주율 표가 3.13~3.14로 채워지는지 확인합니다.

`node tests/wonju-e2e.js` 로 원주 탐험대를 교사 1 + 학생 8명으로 1~4단계 끝까지 해 봅니다 (중간 새로고침 이어 풀기, 범위 밖 측정값 안내, 시상식 포함).

`node tests/ai-e2e.js` 로 우리 반 AI 연구소를 교사 1 + 학생 8명으로 1~4단계 끝까지 해 봅니다 (손그림을 흉내 낸 그림 72개로 학습, 데이터 지우기, 평가 40번의 정확도 확인, 시상식 포함).

`node tests/tower-e2e.js` 로 문장 탑 쌓기를 교사 1 + 학생 10명(5조)으로 한 판 해 봅니다 (세 단계, 틀린 낱말 표시, 따라 쓰기, 황금 블록, 새로고침 이어 하기, 시간 끝, 시상식, 한 판 더).

`node tests/tradelab-e2e.js` 로 무역 실험실을 교사 1 + 학생 10명(5나라)으로 1~4단계 끝까지 해 봅니다 (짝 동시 생산, 무역 10번, 거절·창고 부족 제안, 1라운드 8개 → 2라운드 40개 꾸러미 확인, 새로고침 이어 풀기, 보기 2개 모드, 시상식 포함).
