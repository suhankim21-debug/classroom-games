# classroom-games

6학년 수업에서 쓰는 웹 게임 모음입니다. GitHub Pages로 배포합니다.

- `trade/` 무역 왕국 (사회 2단원 13차시): 짝이 한 나라가 되어 자원을 주고받아 상품을 만드는 실시간 게임. 실시간 데이터는 Firebase Realtime Database의 `rooms/` 아래에 저장됩니다.
- `urimal/` 우리말 지킴이 (국어 4단원 8~10차시를 한 차시로): 학생 한 명이 태블릿 한 대로 언어생활 점검 → 바꿔 말하기 미션 → 실천 다짐문 쓰기 → 친구 다짐문에 의견 주고 고쳐 쓰기 → 스스로 점검·챌린지까지 해요. 교사 화면이 단계를 열고, 우리 반 점검 결과 그래프와 다짐문 모음을 보여 줘요.
- `circle/` 원의 둘레와 넓이 실험실 (수학 5단원 2~6차시): 원리를 눈으로 보여 주는 시뮬레이터. ① 원 굴리기(원주는 지름의 3배보다 조금 김, 정육각형·정사각형 비교) 🔎 왜 3.14일까?(지름 길이 끈을 원에 감으면 3번 감고 지름의 0.14만큼 남음, 원 안·밖 정다각형의 변을 6·12·24·48·96개로 늘리면 둘레÷지름이 3과 4 사이에서 3.14로 좁혀짐) ② 원주율 찾기(물건마다 원주를 펼쳐 지름 막대로 재기, 표·그래프, 원주·지름 계산) ③ 넓이 어림하기(모눈, 안쪽·바깥 정사각형, 반지름 정사각형 몇 개) ④ 잘라 붙이기(부채꼴을 엇갈려 붙여 직사각형으로). 서버 없이 TV와 태블릿 어디서나 열려요.
- `wonju/` 원주 탐험대 (수학 5단원 2차시, 학생 참여형 실시간): 원의 구성 요소 다시 보기 → 원 굴리기 실험(원주와 지름 3개·4개 비교, 원 안 정육각형·원 밖 정사각형) → 짝과 교실의 둥근 물건을 재어 올리면 TV에 지름-원주 그래프 → 원주 어림 대결(12문제, 순위표와 시상식). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `pi/` 원주율 연구소 (수학 5단원 3차시 "원주율 알아보기", 학생 참여형 실시간): 1 수레바퀴 가(지름 5 cm)·나(지름 7 cm)를 자 위에 한 바퀴 굴려 원주를 재고, 계산기로 (원주) ÷ (지름)을 소수 첫째 자리까지 써요(교과서 110쪽) → 2 짝과 교실의 둥근 물건을 재어 지름·원주·원주율(반올림하여 소수 둘째 자리)을 올리면 앱이 계산을 확인하고(두 번 틀리면 풀이), TV에 우리 반 원주율 수직선·평균·잰 물건 표 → 3 원주율 개념 확인 5문제(소고 66 ÷ 21 포함) → 4 원주율 대결 12문제(계산기 사용, 순위표·시상식·많이 틀린 문제). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `hoop/` 굴렁쇠 레이스 (수학 5단원 4차시 "원주와 지름을 구하는 방법 알아보기", 학생 참여형 실시간): 1 지름 60 cm 굴렁쇠가 한 바퀴 간 거리 = 원주, (원주) = (지름) × (원주율) 식을 고르고 지름 × 3.14 칸을 채우면 굴렁쇠가 자 위를 굴러 확인해요(굴렁쇠·자전거 바퀴·훌라후프, 교과서 112쪽) → 2 전통 가옥 기둥 둘레 91.06 cm로 (지름) = (원주) ÷ (원주율)을 구하면 둘레를 펼쳐 지름 막대가 약 3.14번 들어가는 모습을 보여 줘요(교과서 113쪽). 곱하기·나누기를 바꾼 실수, 원주율 3·3.1, 나누는 순서 실수를 알아보고 안내하고 두 번 틀리면 풀이 → 3 짝과 같은 조에서 동전 던지기(지도서 수업 활동 아이디어): 앞면이면 지름을 보내고 짝이 원주를, 뒷면이면 지름을 몰래 정해 원주를 계산해 보내고 짝이 지름을 구해요. 식을 먼저 고른 뒤 답, 세 번 틀리면 풀이. 짝이 없으면 8초 뒤 🤖 로봇 짝이 문제를 내고 풀어 줘요. TV에 조별 표 → 4 굴렁쇠 레이스 12문제(교과서 113쪽 접시 가·나·다, 반지름, 호수 가로등, 10바퀴 굴린 거리 등, 계산기 사용), TV 경주로에서 점수만큼 굴렁쇠가 굴러가고 시상식·많이 틀린 문제. 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.
- `target/` 과녁 넓이 연구소 (수학 5단원 5차시 "원의 넓이 어림하기", 학생 참여형 실시간): 1 국궁 과녁판 노란색 원(반지름 6 cm, 교과서 114쪽)의 넓이를 눈으로 어림해 쓰고(TV에 우리 반 눈 어림 점 그래프), 한 변을 모르는 원 안 정사각형은 마름모로 보고 12 × 12 ÷ 2 = 72, 원 밖 정사각형 12 × 12 = 144를 칸 채우기로 구해 72 cm² < (원의 넓이) < 144 cm²를 써요. ÷ 2를 빠뜨리거나 반지름으로 계산하면 알려 주고 두 번 틀리면 풀이, 빨리 끝낸 친구는 ⭐ 정육각형 도전(지도서 수업 활동 아이디어, 180~240) → 2 모눈(한 칸 1 cm²)에서 원의 4분의 1을 손가락으로 칠해요: 원 안에 완전히 들어간 칸은 초록(22칸 × 4 = 88), 원이 지나가는 칸은 주황(11칸, 걸친 칸까지 132). 두 번 틀리면 빠진 칸·더 칠한 칸을 표시해요. TV에서 원 전체 모눈과 0.5 cm 모눈(98~121)으로 범위가 좁아지는 것을 보여 줘요 → 3 짝과 교실의 둥근 물건(손거울·CD·접시 등) 지름을 자로 재어 넣으면 그 크기의 원을 모눈에 그려 줘서 직접 칠하고 넓이 범위를 구해요(눈 어림과 비교, TV에 물건별 정사각형·모눈 범위 막대) → 4 과녁 맞히기 12문제(TV에서 점수만큼 화살이 과녁으로 날아가요, 시상식·많이 틀린 문제). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.

## 학생 화면 보기 (모든 실시간 게임 공통, `common/watch.js`)

- 선생님 화면 왼쪽 아래 **👀 학생 화면** 버튼: 학생마다 같은 크기의 글자 카드로 보여요. 번호·이름, 지금 단계, 지금 하는 일(문제, 쓰고 있는 글자, 화면에 뜬 안내, 들어가기에서 아직 안 한 것), 도움 요청, 1분 넘게 그대로, 연결 끊김. 카드를 누르면 그 학생 화면을 태블릿 세로 크기(820px)로 고정해 잘림 없이 보여 줘요(기기 크기·회전·스크롤과 상관없이).
- **단계별 화면** 탭: 활동의 모든 단계를 순서대로 한눈에 보여 줘요(지나온 단계 포함). 단계마다 입력 글자를 지운 예시 화면, 지금 그 단계에 있는 학생 수와 번호가 나와요. 단계를 누르면 태블릿 테두리 속 큰 안내용 화면과 이전/다음 단계 버튼이 나와서 TV로 "지금 이 화면이에요" 하고 안내할 수 있어요. 학생 카드를 눌러 보는 화면은 🔴 실시간 표시가 붙은 그 학생의 실제 화면이에요.
- **시작 전 대기**: 선생님 화면 아래 가운데 **▶ 학생 활동 시작** 버튼을 누르기 전까지, 들어간 학생 화면은 "⏳ 잠깐 기다려요" 화면으로 덮여요(이름 쓰고 들어가기까지는 할 수 있어요). 시작한 뒤에는 **⏸ 학생 잠깐 멈추기**로 다시 멈출 수 있어요. 새 방을 만들면 늘 대기부터 시작해요. 무역 왕국·우리말 지킴이·원주 탐험대·원주율 연구소·굴렁쇠 레이스·과녁 넓이 연구소·AI 연구소·무역 실험실·세계 무역 박람회·세계 무역 작전실·말글 탐정단에 들어 있어요(도서관 가는 길·문장 탑 쌓기·추리 게임은 원래 선생님이 시작해야 열려요). 저장 위치는 `rooms/<방 번호>/go`.
- 학생 화면 오른쪽 아래 **🙋 도와주세요** 버튼: 선생님 화면에 알림과 소리가 나고, 선생님이 "확인했어요"를 누르면 학생 화면에 알려요.
- 학생 들어가기 화면: QR로 들어오면 방 번호는 확인 표시만, "번호"와 "이름" 칸을 나눠서(한 칸에 "7 김민수"로 써도 나눠 줘요), 무엇이 빠져서 버튼이 안 눌리는지 바로 아래 할 일 목록으로 보여 줘요.
- **📱 내 휴대폰으로 보기**: `?room=방번호#watch` 주소(QR)로 선생님 휴대폰에서 학생 화면만 볼 수 있어요. TV에는 띄우지 않아도 돼요.
- 데이터는 Firebase `rooms/<방 번호>_watch/` 아래에 저장해요(게임 방 데이터와 따로라 TV가 느려지지 않아요).

## 생각 먼저 쓰기 (자기 생각을 쓰는 활동 공통, `common/think.js`)

아이들이 보기·예시를 그대로 고르지 않고 스스로 생각하게 하는 공통 방식이에요. 탐구 질문, 짧은 글, 까닭 쓰기처럼 **정답이 없는 쓰기 칸**에 씁니다.

- 쓰기 칸에는 완성된 예시 답을 보여 주지 않아요(placeholder도 "내 생각으로 써요"처럼). 방법을 보여 줄 예시가 필요하면 **다른 주제**로 보여 줘요.
- 💡 실마리는 처음에 잠겨 있어요(기본 40초). 먼저 스스로 써 보고, 막히면 ① 생각을 여는 **질문 실마리**(베낄 문장이 없음) → 15초 뒤 ② 빈칸(…)이 있는 **문장 시작 틀**을 열어요.
- 낸 글이 예시·보기와 거의 같으면(글자 쌍 유사도 0.6 이상, 친구 글은 0.8 이상) "내 말로 바꿔 써요" 하고 다시 쓰게 해요. … 자리를 비워 두어도 다시 쓰게 해요.
- 선생님 화면에 "🧠 스스로 ○명 · 💡 질문 실마리 ○명 · ✏️ 시작 틀 ○명"과 학생별 실마리 단계를 보여 줘요(👀 학생 화면 카드에도). 저장 칸은 `hint`(0·1·2).
- 🌟 쉬운 화면(특수교육대상)은 지금처럼 보기에서 고를 수 있어요.
- 쓰는 법: `ThinkFirst.mount(상자, {key, wait:40, hints:[질문 HTML, 시작 틀 HTML], onShow})` → `.level()`, `ThinkFirst.copied(글, [예시들])`, `ThinkFirst.summary(단계들)`. 테스트에서는 주소에 `&tfwait=초`.
- 적용: `globe/` 3단계 탐구 질문, `reader/` 4단계 맞춤 편집자.
