# classroom-games

6학년 수업에서 쓰는 웹 게임 모음입니다. GitHub Pages로 배포합니다.

- `trade/` 무역 왕국 (사회 2단원 13차시): 짝이 한 나라가 되어 자원을 주고받아 상품을 만드는 실시간 게임. 실시간 데이터는 Firebase Realtime Database의 `rooms/` 아래에 저장됩니다.
- `urimal/` 우리말 지킴이 (국어 4단원 8~10차시를 한 차시로): 학생 한 명이 태블릿 한 대로 언어생활 점검 → 바꿔 말하기 미션 → 실천 다짐문 쓰기 → 친구 다짐문에 의견 주고 고쳐 쓰기 → 스스로 점검·챌린지까지 해요. 교사 화면이 단계를 열고, 우리 반 점검 결과 그래프와 다짐문 모음을 보여 줘요.
- `circle/` 원의 둘레와 넓이 실험실 (수학 5단원 2~6차시): 원리를 눈으로 보여 주는 시뮬레이터. ① 원 굴리기(원주는 지름의 3배보다 조금 김, 정육각형·정사각형 비교) ② 원주율 찾기(물건마다 원주를 펼쳐 지름 막대로 재기, 표·그래프, 원주·지름 계산) ③ 넓이 어림하기(모눈, 안쪽·바깥 정사각형, 반지름 정사각형 몇 개) ④ 잘라 붙이기(부채꼴을 엇갈려 붙여 직사각형으로). 서버 없이 TV와 태블릿 어디서나 열려요.
- `wonju/` 원주 탐험대 (수학 5단원 2차시, 학생 참여형 실시간): 원의 구성 요소 다시 보기 → 원 굴리기 실험(원주와 지름 3개·4개 비교, 원 안 정육각형·원 밖 정사각형) → 짝과 교실의 둥근 물건을 재어 올리면 TV에 지름-원주 그래프 → 원주 어림 대결(12문제, 순위표와 시상식). 실시간 데이터는 Firebase `rooms/` 아래에 저장됩니다.

## 자동 테스트

`node tests/trade-e2e.js` 로 배포된 무역 왕국을 Playwright로 끝까지 플레이해 봅니다 (교사 1 + 학생 5나라, 보내기 29번, 상품 10개). 테스트 방은 끝나면 지웁니다.

`node tests/urimal-e2e.js` 로 우리말 지킴이를 교사 1 + 학생 8명으로 1~4단계 끝까지 해 봅니다.

`node tests/circle-e2e.js` 로 원의 둘레와 넓이 실험실의 네 화면을 차례로 눌러 보고 오류가 없는지, 원주율 표가 3.13~3.14로 채워지는지 확인합니다.

`node tests/wonju-e2e.js` 로 원주 탐험대를 교사 1 + 학생 8명으로 1~4단계 끝까지 해 봅니다 (중간 새로고침 이어 풀기, 범위 밖 측정값 안내, 시상식 포함).
